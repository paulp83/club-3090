No pair differed significantly (best McNemar p = 0.25). Three findings shaped the next step:

  1. The task set split three ways. 6 tasks every config solved, 4 tasks separated configs, and 10 tasks no config solved. Ten all-fail tasks is a warning sign, not proof of a hard bench.
  2. 8 of those 10 were unfair as written. Reading the failures across all configs showed the hidden tests checked something the text never stated: an exact CLI (catalog.sh rename/update, #1209), a new function name (gpu_vram_report_lines, #1571), unmentioned edge cases (#1518, #1555, #1610, #1612), a plan line (#1564), or one exact sentence the agents had paraphrased correctly (#1621). Only #1174 and #1510 were genuine misses. Step-4 screening missed them because it only read failure messages printed before the fix.
  3. GLM ran far faster than expected: about 13 minutes per task, level with Strata, not the 30–60 the quality packs suggested. Agent turns are short, so decode speed matters less than in long-answer packs.

Pivot (2026-10-11): rather than drop the 8 (leaving 12 tasks, too few to rank anything), each got an ## Interface section, and they re-ran on every config. Draw 1 then covers 20 fair tasks. The original-text results for those 8 stay in runs/<config>/draw1-v1/ as a before/after record of what the missing details cost each config.

No regressions in 140 runs; one run hit the 100-step limit (Strata IQ4_XS, #1588, which it still solved on the working tree). What the details say that the solve rate can't:

  1. 9 tasks separate the configs. Across all 140 runs, 9 tasks were solved every time (#1172, #1203, #1209, #1307, #1464, #1470, #1564, #1608, #1621) and 2 never (#1174, #1510). The other 9 carry every difference: #1204, #1518, #1555, #1556, #1571, #1573, #1588, #1610, #1612. The Interface sections overshot: 5 of the 8 revised tasks went from solved by nobody to solved by everyone.
  2. Strata UD-IQ4_XS leads, but not significantly. Its best paired gap on draw 1 is 4 tasks to 0 against Strata Q4_K_XL, GLM IQ4_XS and ThinkingCap (McNemar p = 0.12 each). It's the only config to solve #1556 and #1555, and it solved #1573 and #1612 in both draws. The smaller Flash Next quant beats the larger one, 31 to 25 of 40.
  3. ThinkingCap is the most repeatable; Strata is not. Between draw 1 and draw 2, ThinkingCap changed its result on 1 task (#1571), Strata Q4_K_XL on 3, Strata IQ4_XS on 5 (#1204, #1518, #1555, #1556, #1588). A one-draw gap of 3 to 4 tasks is inside Strata's own run-to-run spread, so the GLM figures (one draw each) are softer than they look.
  4. ThinkingCap leads on throughput, by less than the last snapshot said. On the 9 tasks everyone solved it takes a median 2.2 minutes, against 6 to 9 for the others at similar step counts (15 to 33). Correction: Strata IQ4_XS's draw 1 overlapped a duplicate run of itself, which inflated its times. Its clean draw 2 is 6.0 min/task, 11 s/step and 5.4 solved per agent-hour (not 12.1, 21 and 3.5). ThinkingCap's lead over Flash Next is now about 1.3× per agent-hour, not 2×.
  5. ThinkingCap gives up early; Flash Next persists. ThinkingCap's failures end in 2.5 to 9 minutes. The tasks only Flash Next solved are the long ones: #1588 (100 steps, 44 min), #1556 (26 min), #1573.
  6. GLM is terse and precise. The best file localization (0.93 to 0.96) and the fewest tokens per step; avar6 alone among the bare draw-1 runs solved #1204, the hardest task here (93 steps). Its two quants sit one task apart, as in the quality packs. Slower turns hold it to about 2.4 solved per agent-hour.

Harness and scoring fixes found along the way

All applied before the numbers above, or re-scored.

  • The SWE-bench config sets BASH_ENV=/root/.bashrc. Run as a non-root user, every command printed a permission error, which broke the submit step. Dropped BASH_ENV, set HOME=/tmp.
  • Scoring the agent's submitted text made the score depend on the submit ritual. Switched to scoring the working tree.
  • Some tests print only failures plus a PASS: N FAIL: M total. The check counter skipped totals, so a 12-of-15 near miss scored 0.0. It now uses the total; the references were recounted and finished runs re-scored (--rescore).
  • Strata IQ4_XS's draw 1 briefly ran two copies of itself at once (a restarted chain left a run behind). The second run overwrote every task, so results are single-run, but its draw-1 times are inflated. Use draw 2 for its timing.
  • A process check using pgrep -f <pattern> matched the checking shell's own command line and reported a finished run as still going. Check result files, not process names.
  • Strata listens on 127.0.0.1 by default, which the club quality harness's sandboxes can't reach; serve it on --host 172.17.0.1 for any containerised harness.
  • omp's print mode lacks some tools its interactive mode has (find, ast_grep, checkpoint, rewind, context_notes). Listing them failed the run, so the omp arm uses read, bash, edit, write, glob, grep, ast_edit, todo, task, wait, eval.
  • report.py counted the archived draw1-v1 folder as a draw, which double-counted the 8 revised tasks. It now reads only draw<N> folders.
